# Геоданные для карты

Границы регионов Казахстана и список городов. Всё собирается одной командой и работает без интернета.

**Источник:** [OpenStreetMap](https://www.openstreetmap.org/copyright), © участники OpenStreetMap, лицензия ODbL 1.0. В интерфейсе рядом с картой обязательна подпись «© участники OpenStreetMap».

## Файлы

| Файл | Что внутри |
|---|---|
| `kz-regions.geojson` | 20 регионов: 17 областей (в том числе Абайская, Жетысуская и Улытауская, созданные в 2022 году) и города Астана, Алматы, Шымкент. Свойства: `id` (код ISO 3166-2, например `KZ-15`), `name_ru`, `kind` (`oblast` или `city`) |
| `kz-region-borders.geojson` | Внутренние границы между регионами, линии |
| `kz-outline.geojson` | Контур страны: `part=country` — полигон, `part=contour` — одна линия внешней границы для анимации |
| `kz-regions.json` | Справочник регионов: названия на русском, казахском и английском, варианты для поиска, центр (`center`), рамка `bbox` = [запад, юг, восток, север] |
| `kz-cities.json` | 195 городов и посёлков: названия на трёх языках, старые названия, регион, население, координаты, признак центра региона |

Границы упрощены до 10% точек: все файлы вместе весят около 0,5 МБ.

## Как пересобрать

Нужны интернет и Node.js.

```bash
python scripts/build_geo.py
python scripts/build_geo.py --simplify 6%
```

Скрипт:
1. берёт список регионов из Overpass API (`admin_level=4` внутри Казахстана);
2. скачивает границы каждого региона с сервиса полигонов OSM;
3. восстанавливает анклавы как дыры: Астана внутри Акмолинской области, Алматы внутри Алматинской, Шымкент внутри Туркестанской;
4. упрощает границы через mapshaper с сохранением общей топологии, чтобы соседние регионы не расходились;
5. берёт города и посёлки (`place=city|town`) и относит каждый к региону по координатам.

Сырые выгрузки кэшируются в `data/raw/geo/` и в git не попадают.

## Ручные правки поверх OSM
- Улытауская область: в OSM записана как «Улутауская», название исправлено, исходное оставлено как вариант для поиска.
- Центр Алматинской области — Конаев (с 2022 года).
- Добавлены старые названия городов (Алма-Ата, Актюбинск, Капчагай, Семипалатинск…) и сокращения областей (ВКО, ЗКО, СКО, ЮКО).
