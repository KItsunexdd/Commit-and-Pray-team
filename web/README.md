# Jana Address — веб-интерфейс

Готовый интерфейс: React + Vite + TypeScript (strict), Tailwind, локальные шрифты,
дизайн-токены, клиент API с демонстрационными ответами, объёмная карта Казахстана
и HUD, поиск городов и областей с подлётом к региону, разбор полного адреса
с подсветкой полей и адаптивной карточкой результата, фоновые эффекты с ограничением нагрузки,
проверка JSON-файла с редактором и строгой выгрузкой, аналитика файла на карте,
демо адресов, экран «Как это работает» и запасная SVG-карта без WebGL.

## Запуск

Нужен Node.js 22.19 или новее (включая Lighthouse). В VS Code откройте папку
`C:\terriconV`, затем **Терминал → Создать терминал** (PowerShell):

```powershell
cd C:\terriconV\web
npm ci
npm run dev
```

`npm ci` нужен при первой установке или изменении зависимостей. Для повторного
запуска достаточно `npm run dev` из папки `web/`; остановка — `Ctrl+C`.

Открыть http://127.0.0.1:5173. Установка зависимостей требует сети; готовая сборка
загружает ресурсы только со своего сервера. Шрифты Inter и JetBrains Mono
включены в сборку с подмножествами cyrillic и cyrillic-ext. Для недостающих
казахских букв в JetBrains Mono используется локальный Noto Sans Mono.

Для демонстрационных ответов создать локальный файл `web/.env.local`:

```dotenv
VITE_USE_MOCKS=true
VITE_API_BASE=/api
```

Файл не попадает в git. Без флага `VITE_USE_MOCKS=true` клиент обращается к реальному
API. После изменения переменных перезапустить Vite. **`npm run build` всегда
выключает моки**, независимо от `.env.local`: готовая сборка использует реальный API.
`VITE_API_BASE` — только путь на том же сервере, без домена, например `/api`.
В режиме разработки этот префикс проксируется на `http://localhost:8000`
без переписывания пути; он должен совпадать с `API_PREFIX` бэкенда.

## Проверки

```powershell
npm run lint
npm run typecheck
npm test
npm run build
npm run preview
```

Предпросмотр сборки: http://127.0.0.1:4173. `preview` отдаёт только статические
файлы; реальный API должен обслуживаться FastAPI на том же origin.
`dist/` включён в финальный коммит. Скрипт `copy-geo.mjs` перед разработкой
и сборкой копирует пять файлов из `../data/geo/` в `public/geo/`, не изменяя оригиналы.
`public/geo/` игнорируется; копии внутри `dist/geo/` входят в готовую сборку.

Проверка после добавления тем, режима без карты и экспорта и финальных исправлений:
lint, typecheck, тесты Vitest и production-сборка проходят. На 375 px и 1440 px проверены
светлая и тёмная темы, главная страница, карточка и мобильная шторка, файл,
аналитика, справочник, скрытие/возврат карты и SVG. Полное демо без карты
прошло на моках; в production без API оно остановилось на первом запросе с ошибкой.
При скрытии сохранённого WebGL-холста счётчики кадров и отрисовок перестали расти;
возврат восстановил тот же холст и выбранный результат. Копирование одной записи
показало подтверждение, меню выгрузило все пять записей и три записи фильтра.
XLSX дополнительно прочитан независимой библиотекой openpyxl: проверены ZIP/CRC,
XML, листы, текстовые ячейки, казахские буквы и закрепление заголовка. Новые
зависимости в приложении не появились; модуль XLSX загружается только при экспорте.
Эти проверки выполнены в браузере с размерами окна телефона, не на физическом устройстве.
Нового замера Lighthouse для этой версии не проводилось.

После исправлений на 1440 px поиск «Усть-Каменогорск», `scrollIntoView` и попытка
программной прокрутки оставляют `scrollLeft` контейнеров карты равным нулю.
Запасное копирование проверено в браузере с отключённым Clipboard API;
тесты также покрывают отказ обоих способов. Скачанный JSON одной записи — массив
из одного объекта с 14 полями, имя сводки — `Пример адресов-summary.xlsx`.
Подсказка при скрытой карте проверена на 375 px и 1440 px.

## Слой API

Контракт: `../docs/api.md`. `api.parse(records, signal?)` в `src/api/client.ts`
возвращает `items` в исходном порядке. Повторяющиеся `id` не объединяются:
позиция в массиве определяет запись. Ответ проверяется перед передачей интерфейсу.
`explain` допускает `null`, отсутствующие `spans` или `sources`; неверные пояснения
отбрасываются, чтобы подсветка могла использовать поиск по строке.

Моки содержат примеры поиска, все пять адресов демо и вариант адреса Алматы из контракта.
Неизвестная строка возвращает пустые адресные поля и `confidence: 0`.
Это фиксированные примеры для разработки интерфейса, а не локальный парсер.
Сетевые ошибки, отмена запроса и ошибки сервера не заменяются моками.

Основные тексты интерфейса находятся в `src/i18n/ru.ts`, палитры — в
`src/theme/palette.ts`, типографика — в `src/styles/app.css`, цвета полей адреса —
в `src/theme/address-fields.ts`.
В HTML оставлен только начальный заголовок страницы; при запуске он берётся из `ru.ts`.

## Карта и HUD

MapLibre отображает локальные полигоны 20 регионов. При запуске на широком экране
создаются четыре слоя объёма, при ширине меньше 640 px — два. Высота уменьшается при приближении.
Тонкий светящийся контур и швы проецируются на верхнюю поверхность, подписи центров
областей — HTML-элементы. Подписи не используют серверные глифы. Раскладка сначала
сохраняет Астану, Алматы и Шымкент, затем центры областей по населению. Если текст
пересекается, пробует положения слева, справа и снизу, затем скрывает менее важную
подпись. Точки остаются; после приближения подписи возвращаются. Раскладка обновляется
по окончании движения. В аналитике она также учитывает рамки чисел адресов.
При высоте менее 820 px заголовок, подсказки и отступы компактнее; карта занимает
свободную ширину. Сведения об источнике OpenStreetMap находятся внизу экрана.
Рабочий модуль MapLibre включён в сборку через Vite и загружается с того же сервера.

Карту можно перемещать и масштабировать жестами, клавиатурой и кнопками. Кнопка
с рамкой возвращает весь Казахстан. В покое камера неподвижна, WebGL и SVG-контуры
не перерисовываются. Последняя кнопка приостанавливает фоновые эффекты
и пульсацию. Анимации также приостанавливаются в скрытой вкладке и при
`prefers-reduced-motion`. Плотность пикселей ограничена 1.5 на телефоне и 2 на широком экране.

Проверить на размерах 375×667, 390×844, 412×915 и 768×1024: целостность контура,
читаемость городов, работу масштаба и сброса, отсутствие горизонтальной прокрутки.
В Network должны быть только локальные запросы. Если WebGL недоступен,
автоматически открывается запасная SVG-карта.
По внешнему контуру движется один световой импульс с затухающим хвостом.

## Поиск города или области

Поиск работает по локальным `kz-cities.json` и `kz-regions.json`: русские,
казахские, английские и старые названия, сокращения областей и небольшие опечатки.
Одноимённые населённые пункты остаются отдельными вариантами с подписью региона.
Если строка не соответствует локальной подсказке, Enter отправляет её в API разбора.

Выбор подсказки или Enter запускает подлёт к границам региона за 2,4 секунды.
Его высота плавно увеличивается до ×1,8, но не ниже 2500 м для выбранного региона,
появляется контур со свечением и рамка,
остальные регионы приглушаются. При выборе города пульсирует точка именно этого
города; при выборе области центр подписан без пульсации. Алматы, Астана и Шымкент
показываются как отдельные регионы; подлёт к ним ограничен масштабом 9.5,
чтобы сохранить окружение. Контуры и подписи следуют той же высоте, что и поверхность.
Новый выбор отменяет предыдущий полёт.

Стрелки вверх/вниз выбирают подсказку, Enter подтверждает, Escape или «Сбросить»
возвращают весь Казахстан и очищают поле. При `prefers-reduced-motion` переход
происходит без полёта: вид меняется через затухание 250 мс. Кнопка паузы управляет
фоновым движением, не мешая ручному выбору.
Подсказки учитывают доступную высоту `visualViewport` при открытой клавиатуре.

Для ручной проверки: «актюбинск», «Ақтөбе қаласы», «алмата», «Almaty Region»,
«ВКО», «Нур-Султан», «Шымкент» и неизвестное название. Проверить быстрый выбор
двух разных целей, сброс во время полёта и смену ширины с выбранным регионом.
Проверены 375×667, 390×844, 412×915, 768×1024 и 1440×900: без горизонтальной
прокрутки, поля 16 px, кнопки от 44 px, только локальные ресурсы. Экранную клавиатуру
и плавность на реальном Android дополнительно проверить на устройстве.

## Разбор адреса

Исходная строка передаётся без изменений в `POST /api/ui/parse`. Для локальной
разработки без запущенного API можно включить демонстрационные ответы с `VITE_USE_MOCKS=true`.
Новый ввод, очистка или Escape отменяют предыдущий запрос; запоздавшие ответы
не меняют результат. Есть индикатор ожидания, отмена, повтор при ошибке
и ограничение ожидания в 30 секунд.

Карта выбирает область по `province`, при отсутствии совпадения — по `city`.
Если область известна, а город нет, показывается область без выдуманной точки.
Неоднозначный город без области не выбирается автоматически. При смене
размера окна вызывается `map.resize()`, пересчитываются камера и плотность пикселей;
холст и слои сохраняются вместе с выбранным местом и карточкой.

На широком экране результат появляется справа, при ширине меньше 1000 px —
в нижней шторке. Её ручку можно потянуть, нажать или использовать стрелки
вверх/вниз; содержимое прокручивается отдельно. Закрытие возвращает фокус в поиск.
Карточка содержит исходную строку, 11 полей, источники и общую уверенность разбора.
Рядом с процентом указано: «эвристическая оценка, не вероятность».
Значения ниже 60% отмечаются как требующие проверки. Уверенность отдельных полей
API не передаёт. Пустые поля показаны как «Не найдено».

Подсветка использует `explain.spans`. Если пояснений нет или они неполные,
значения ищутся в исходной строке без учёта регистра, с защитой от совпадений
внутри других слов и чисел. Словарные поля не получают выдуманных интервалов;
неизвестный источник подписан явно. Цветные метки в списке служат легендой.

Ручная проверка: отправить пять примеров из плейсхолдеров, затем неизвестный адрес.
Для Алматы проверить квартиру 70 и район «Ауэзовский» из справочника; для
«Туран 55/6 магазин береке 4подьезд 9этаж» — предупреждение при 55% и отсутствие
выбранного города. Проверить раскрытие и сворачивание шторки, прокрутку всех полей,
закрытие, Escape, повторный разбор и смену ширины с открытым результатом.

Проверены размеры 375×667, 390×844, 412×915, 768×1024 и 1440×900 на моках:
горизонтальной прокрутки нет, поле 16 px, видимые кнопки от 44 px,
ресурсы загружаются только со своего сервера. Автоматические проверки покрывают
разрешение региона, подсветку с пояснениями и без них, сохранение исходного текста,
ошибки, отмену, тайм-аут и гонку ответов. Реальный API подключить и проверить
после готовности бэкенда; экранную клавиатуру дополнительно проверить на устройстве.

## Эффекты и производительность

Отдельный прозрачный Canvas с `pointer-events: none` рисует редкие частицы,
каркасные волны снизу, сканлинии, виньетку и две небольшие цифровые панели
на широком экране. Панели декоративные, не показывают состояние API.
Текст, поиск, карта и кнопки остаются доступными для мыши, касаний и клавиатуры.

Один импульс проходит контур за 10 секунд. После выбора места он переходит
на внешний контур выбранной области. Его положение вычисляется по расстоянию
в географической проекции, поэтому поворот, подлёт и подъём не сдвигают его
относительно границы. Для многочастной области используется основной внешний контур.
Отрисовка использует те же проецируемые вершины верхней грани, что и SVG-контуры:
так импульс совпадает с объёмом и не скрывается под полигонами.

В обычном режиме эффекты ограничены 15 кадрами/с и 56 частицами.
Через 20 секунд без действий пользователя canvas останавливается; движение указателя,
касание, ввод или прокрутка возобновляют его с прежнего места. Ручная пауза,
скрытая вкладка и системное уменьшение движения сохраняют приоритет.
Атрибут `data-frame` обновляется только в тестовом режиме, в production его нет.
Число частиц уменьшается пропорционально площади. Плотность пикселей Canvas —
максимум 1. В светлой теме рисуется только импульс и очищается только его предыдущая
область. Во время движения карты эффекты приостановлены. Геометрия SVG-контура
упрощается по масштабу (1 404 вершины на обзоре вместо 8 397) и кешируется.
Свечение контура сделано штрихом без SVG-фильтра, поиск и карточка имеют плотный фон
без `backdrop-filter`. Плотность пикселей карты — максимум 2 на широком экране.

При ширине меньше 640 px либо доступных сведениях о ≤4 логических ядрах или ≤4 ГБ памяти сразу включается
облегчённый режим. Он также включается после прогрева 1,5 с, если в трёх последовательных
секундных окнах не менее 70% интервалов rAF превышают 50 мс. Измеряется вся страница,
включая подлёт, независимо от паузы canvas. В этом режиме эффекты полностью отключены,
плотность пикселей карты — 1. MSAA отключён при создании WebGL-контекста,
чтобы позднее снижение качества не требовало его замены. Качество не повышается до перезагрузки,
чтобы избежать повторных переключений. Если режим включён при создании карты,
используются два слоя и один рабочий поток; при позднем включении карта не пересоздаётся.

Кнопка паузы останавливает Canvas, пульсацию и смену
примеров в поиске; при открытой мобильной карточке она перемещается в шапку.
Ручной выбор места остаётся доступен. В скрытой вкладке циклы эффектов отменяются,
а незавершённый подлёт завершается без анимации. После возврата часы эффектов
продолжаются без скачка. При `prefers-reduced-motion` нет полётов, частиц,
импульса, сканирующей полосы и смены примеров; остаются четыре статичные волны
и неподвижные сканлинии в тёмной теме. Ручное перемещение карты обновляет статичный фон.

Проверки оптимизации: тесты Vitest, lint, typecheck и production-сборка.
Замеры до и после, ограничения методики и сценарии — в [PERFORMANCE.md](PERFORMANCE.md).

Проверить: стартовую карту, выбор города и области, разбор полного адреса,
паузу/возобновление до и после выбора, переход через ширину 640 px, скрытие вкладки
и системное уменьшение движения. В браузерной проверке использованы размеры
375×667, 390×844, 412×915, 768×1024 и 1440×900; режимы уменьшенного движения,
слабого устройства и скрытой вкладки дополнительно проверены с тестовой эмуляцией.
Плавность на физическом Android нужно дополнительно проверить на устройстве;
результаты Lighthouse приведены ниже.

Визуальные ориентиры: [Waves Background](https://21st.dev/@deleted_reactbits/components/waves-background.md)
и [Letter Glitch](https://21st.dev/@deleted_reactbits/components/letter-glitch.md).
Принцип расстояния вдоль линии: [пример MapLibre](https://maplibre.org/maplibre-gl-js/docs/examples/create-a-gradient-line-using-an-expression/).
Эффекты написаны локально, без копирования кода компонентов и новых зависимостей.

## Демо для защиты

Кнопка «Демо», Shift+D или `/?demo=1` запускает пять адресов по порядку:

1. «город Алматы/Алматы қаласы, Мкр Аксай 3а, 59, кв 70».
2. «город Актобе/Ақтөбе қаласы, Назарбаева8».
3. «Турксибский район, Рыбинский переулок, дом 4».
4. «Туран 55/6 магазин береке 4подьезд 9этаж».
5. «66квартал 12дом 69квартира».

Сначала демо ждёт готовности 3D-карты (либо постоянного SVG при отказе WebGL),
показывая «ПОДГОТОВКА КАРТЫ». Это относится и к `?demo=1`. Затем текст появляется
примерно по символу за 25 мс и выполняется обычный разбор.
После карточки и завершения подлёта — пауза 4 секунды; в конце карта возвращается
ко всему Казахстану. HUD показывает номер адреса. «Пауза» приостанавливает сценарий
и полёт, «Стоп» и Escape завершают его. Пользовательский ввод и переход к файлам
или справочнику останавливают демо; скрытие вкладки ставит его на паузу.
Автозаполнение не открывает экранную клавиатуру.

Демо использует тот же клиент, что и поиск. В разработке полный сценарий проверяется
с `VITE_USE_MOCKS=true`; в production — только настоящий API. При ошибке сценарий
останавливается с понятным сообщением и сохраняет введённый адрес, без замены ответа.
Подлёт возможен только когда ответ определяет место; город не угадывается.

## Проверка файла

Ссылка в шапке открывает `/#files`. Карта остаётся приглушённым фоном, декоративные
анимации приостановлены. Возврат к поиску сохраняет файл, фильтр и правки в памяти
вкладки; незавершённый пакетный разбор останавливается. После перезагрузки данные
нужно загрузить заново. Перед уходом со страницы с невыгруженными результатами
браузер показывает предупреждение.

Вход: UTF-8 JSON с массивом записей или объектом `{ "records": [...] }`.
У каждой записи обязательны строковые `id` и `raw_address`. UTF-8 BOM допускается.
Остальные входные поля не используются для разбора. Ограничения интерфейса —
10 МБ и 25 000 записей; пустые, повреждённые и неподходящие файлы отклоняются
до отправки. Ошибка нового файла не удаляет текущие результаты. Корректная
замена требует подтверждения на экране.

Кнопка «Разобрать адреса» отправляет последовательные пакеты по 50 записей в
`POST /api/ui/parse`, используя тот же API-клиент и флаг моков, что и поиск.
Есть прогресс, остановка и продолжение с последнего завершённого пакета.
Тайм-аут одного пакета — 60 секунд. Ошибка, отмена и поздний ответ не перезаписывают
готовые записи или ручные правки. Повторяющиеся `id` разрешены: ключ строки,
редактор и результат привязаны к позиции в массиве.

На широком экране — таблица, до 1000 px — карточки. На странице не более 25 записей.
Фильтр «Нужна проверка» использует строго `confidence < 0.6`; ручная правка не меняет
уверенность сервиса и не исключает запись из фильтра. Исходный текст подсвечивается
по тем же правилам, что и одиночный адрес, найденные значения показаны цветными метками.

Редактор открывается справа, на телефоне до 640 px — на весь доступный экран с учётом
`visualViewport`. Можно изменить 11 адресных полей. Пустое значение сохраняется как
`null`; `id`, `raw_address` и `confidence` доступны только для чтения. Изменённые поля
получают отметку «изменено вручную», устаревшие интервалы подсветки удаляются.
Escape и закрытие при несохранённых правках предлагают продолжить или отменить правку.
Фокус остаётся внутри редактора и возвращается к открывшей его кнопке.

Выгрузка доступна после разбора всего файла. JSON **всегда содержит массив**
`AddressResult[]`, даже если вход был обёрнут в `records`: ровно 14 полей в каждой
записи, без `explain` и отметок интерфейса. Меню «Выгрузить» позволяет выбрать все
записи (по умолчанию) или текущий фильтр: «Нужна проверка», регион либо их пересечение.
Текущая страница таблицы не ограничивает экспорт. Порядок, повторяющиеся `id`,
исходные строки и правки оператора сохраняются. Имена — `<исходное имя>-result.json`,
`-result.csv`, `-result.xlsx`.

CSV: UTF-8 с BOM, разделитель `;`, 14 заголовков — ключи контракта. Кавычки и
переносы экранируются, потенциальные формулы защищены префиксом апострофа.
Excel создаётся без новых зависимостей: ZIP STORE с CRC32 и текстовые `inlineStr`
ячейки. «05» и «1/2» остаются строками. Лист «Адреса» содержит 14 полей и отметки
«Нужна проверка», «Изменено вручную»; лист «Сводка» использует тот же расчёт,
что аналитика, для выбранного объёма. Первая строка закреплена, ширины учитывают
содержимое. Текст длиннее лимита Excel (32 767 знаков на ячейку) не обрезается:
появляется предложение сохранить JSON или CSV. Для сводки нужен загруженный
справочник регионов; при его ошибке JSON и CSV остаются доступны.

В карточке результата «Копировать JSON» копирует объект из 14 полей и показывает
«Скопировано». Если Clipboard API недоступен (например, на `http://IP:8000`) или
отказал, используется временное поле и `execCommand('copy')` с восстановлением фокуса.
«Скачать JSON» сохраняет массив из одной такой записи, как пакетная выгрузка.
Аналитика выгружает `<исходное имя>-summary.xlsx` только с листом «Сводка».
Автоматическое извлечение и уверенность считаются
по исходному ответу, география и рейтинги — с учётом правок.

Быстрая проверка: «Проверка файла» → «Загрузить пример» → «Разобрать адреса».
В примере пять адресов, у первых двух одинаковый `id`. Включить фильтр (три записи
на моках), изменить дом во второй записи, скачать результат и проверить, что
первая запись не изменилась, а выгрузка содержит все пять записей по 14 полей.
Дополнительно загрузить оба допустимых формата, повреждённый JSON и файл более
чем на 50 записей; проверить пагинацию, остановку, продолжение и замену файла.

Проверены размеры 375×667, 390×844, 412×915, 768×1024 и 1440×900: без горизонтальной
прокрутки, поля редактора 16 px, кнопки от 44 px, внешних запросов нет.
Автоматические тесты покрывают строгую выгрузку, повторяющиеся идентификаторы,
правки, пакеты, отмену, тайм-аут, повтор и запоздавшие ответы. Браузерная проверка
выполнена на моках; подключение реального API и экранную клавиатуру на устройстве
проверить при финальной интеграции.

## Аналитика файла на карте

После полного разбора кнопка «Показать на карте» открывает `#main` с аналитикой.
Пять ступеней зелёного показывают число адресов в регионе; границы диапазонов
рассчитываются по максимальному числу адресов в файле. Нулевые регионы обозначены
отдельно; «Не определено» показано серым в легенде. Над центрами — только ненулевые
числа адресов; точки пустых регионов сохраняются.
Одинаково работает в 3D и SVG. Панель справа на десктопе становится шторкой на телефоне.

Регион определяется по `province`: точное нормализованное совпадение с `name_ru`
или `aliases` из `kz-regions.json`. Только при пустом `province` используется `city`
и `region_id` из `kz-cities.json`. Неизвестная непустая область и неоднозначный город
не заменяются догадкой. Повторяющиеся `id` учитываются отдельно по позиции записи.

Карта, топ-5 регионов и городов и показатель «Определён регион» используют текущие
исправленные данные. Число уверенных ответов (`confidence >= 0.6`), извлечённые
квартиры, сочетание квартиры и подъезда и гистограмма считаются по исходному ответу
сервиса, до правок. Отдельно показано количество исправленных записей; рядом с
автоматическим извлечением появляется «без учёта ручных правок».
Пять корзин уверенности: [0; 0.2), [0.2; 0.4), [0.4; 0.6), [0.6; 0.8), [0.8; 1].

Нажатие на регион, строку топа или «Не определено» возвращает в таблицу с видимым
снимаемым фильтром. Есть доступный с клавиатуры список всех регионов. Фильтр можно
совместить с «Нужна проверка». «Выйти из аналитики» и Escape возвращают обычный поиск.

Проверка на моках: разобрать пример, открыть карту (5 адресов, 2 региона определены,
3 неизвестны), поменять у первой записи город на Актобе и очистить область. Карта
перенесёт запись в Актюбинскую область. Добавленный вручную подъезд не увеличит долю
автоматического извлечения. Клик по региону открывает соответствующие строки.

## Как это работает

Ссылка в шапке открывает `/#about`; на телефоне она обозначена `i` с доступным
названием «Как это работает». Пять шагов объясняют разбор строки
«город Алматы/Алматы қаласы, Мкр Аксай 3а, 59, кв 70»: строка → очистка → маркеры →
сверка со справочником → поля. Пример показывает удаление казахского дубля города
и нахождение Ауэзовского района по микрорайону Аксай 3а. Района нет в исходной
строке; подпись объясняет отметку «из справочника» в карточке результата.

При открытии `api.info(signal?)` запрашивает `GET /api/info`. Этот запрос всегда
реальный, даже при включённых моках разбора. Источники, даты, размеры справочника
и метрики берутся из ответа после проверки структуры. Метрики показаны таблицей
с исходными именами `score`, `address`, `details`, `reference`, без округления или
перевода в проценты. Нули сохраняются. При отсутствующем, пустом или `null`-поле
`metrics` показано «Метрика появится после прогона на размеченной выборке».

При сетевой/HTTP-ошибке, некорректном ответе или ожидании дольше 8 секунд показываются
OpenStreetMap и количество записей в загруженных `kz-regions.json` и `kz-cities.json`.
Числа не захардкожены. Подпись: «Сервер недоступен — показаны данные интерфейса».
Если и геоданные не загрузились, числа не подставляются; доступен повтор загрузки.
Повтор запроса API доступен отдельной кнопкой. Уход с экрана отменяет запрос.

Лицензии: OpenStreetMap (ODbL 1.0, «© участники OpenStreetMap») и локальный
`/licenses/maplibre-gl.txt`. Скрипт подготовки копирует текст из установленной
версии MapLibre в `public/licenses/` и затем в `dist/licenses/`; он доступен также
на dev-сервере. Внешние ссылки открываются только по нажатию, удалённые ресурсы
экран не загружает. Фон — статичная SVG-карта; 3D-движок здесь не запускается.

Проверены 375×667, 390×844, 1366×768 и 1920×1080: нет горизонтальной прокрутки
страницы, таблица при необходимости прокручивается внутри блока. Проверены ответ
API по контрактной фикстуре (включая нули), отсутствие метрик, отказ сервера,
тайм-аут, ошибка геоданных, остановка демо при переходе и сохранение загруженного
файла. Фикстуры используются только в тестах, в готовую сборку они не входят.
Живые источники и метрики сверяются с ответом `/api/info` запущенного сервиса.

## Запасная карта и обработка ошибок

Кнопка «Карта» и клавиша M включают и скрывают карту; M не работает при вводе
в поле. Выбор сохраняется в `localStorage` с обработкой запрета хранилища.
Без карты поиск и карточка образуют обычную прокручиваемую страницу, над карточкой
видны город и район. Демо проходит пять адресов без ожидания подлётов, аналитика
показывает полосы регионов с переходом к фильтру файла. Запрос, результат и демо
сохраняются при переключении.

У скрытой карты отключены наблюдатели размеров, циклы эффектов, движения и подъёма,
отменён ожидающий кадр WebGL и заблокированы новые запросы отрисовки. На обычном
режиме сохраняется экземпляр и холст; в экономичном режиме он освобождается.
Ограничитель кадров использует `_frameRequest` закреплённого MapLibre 6.14 — это
нужно перепроверять при обновлении зависимости вместе с `triggerRepaint`.
При первом открытии экрана без карты движок не создаётся.

Светлая тема Jana Post включена по умолчанию. Кнопка солнца/луны в шапке доступна
и на телефоне, сохраняет выбор в `localStorage`; при запрете хранилища переключение
работает до перезагрузки. Параметры `?theme=light` и `?theme=dark` имеют приоритет
при открытии страницы. Цвета определены в `src/theme/palette.ts`: из них собираются
CSS-переменные и палитры WebGL, SVG, canvas, полей адреса и аналитики.
Начальный атрибут `data-theme`, `color-scheme` и `theme-color` устанавливает скрипт
в `head` до рендера. Переключение меняет только краски существующей карты,
сохраняет камеру и подлёт. В светлой теме используются спокойные дуги из макета,
белые швы регионов и контрастные тёмные цвета текста; логотип картинкой не встроен.

Положение карты рассчитывается по реальным `getBoundingClientRect()` блоков
поиска (вместе с подсказкой), панели результата и мобильной шторки. MapLibre
получает абсолютные отступы, которые сохраняются при подлёте с наклоном.
Изменение окна, высоты поиска или размера шторки пересчитывает камеру; SVG
использует ту же свободную область. Проверены Актюбинская, Восточно-Казахстанская,
Мангистауская области и Астана при 1366×768, 1920×1080 и 390×844, а также
карточка результата для Актобе на этих трёх размерах.

Координаты HUD в обзорном виде получаются через `unproject` центра свободной
части карты, а после выбора региона — из его `center` в `kz-regions.json`.
До готовности карты вместо координат и масштаба отображается «—».

Первые 1.2 секунды видны фон выбранной темы, HUD и сообщение загрузки. Если 3D не готов,
показывается SVG, собранный из геоданных без ожидания шрифтов: наклон 44°, поворот
−7° и два тёмных слоя под поверхностью. Его камера, масштаб и отступы передаются
MapLibre; после первого `idle` происходит смена за 400 мс (250 мс при уменьшенном
движении). Если 3D успел раньше порога, SVG вообще не показывается.
Четыре чанка MapLibre предзагружаются через `modulepreload` в собранном `index.html`.
Импорт движка начинается после первого кадра интерфейса, параллельно с геоданными.
Предзагрузка выполняется и на вспомогательных экранах; сам движок там не запускается.

Выбор во время смены движка ставится в очередь и получает полные 2.4 секунды полёта
после `idle`. Если подлёт уже начался в SVG, сохраняются текущая камера и остаток
времени. Изменение размеров карточки или окна также сохраняет остаток полёта.
При необходимом пересоздании карты её SVG-снимок остаётся до новой геометрии.
Уход на экран файлов отменяет отложенный запуск, ошибка импорта оставляет рабочую SVG.

Если WebGL не создаётся или контекст теряется во время работы, карта автоматически
переключается на SVG с `d3-geo`. Выбранный регион сохраняется. Те же 20 полигонов
отображаются с отверстиями городских регионов; HTML-подписи не требуют глифов.
Поиск приближает область целиком, маленькие городские регионы — крупнее.
Работают кнопки масштаба, перетаскивание, pinch-жест, колесо, стрелки и клавиши +/−.
При уменьшенном движении используется короткое затухание. Сброс возвращает всю страну.
В экране файлов SVG используется как приглушённый фон, чтобы не запускать тяжёлый
графический движок. Возврат к поиску восстанавливает объёмную карту.

Принцип расчёта видимой области: [D3 zoom to bounding box](https://observablehq.com/notebook-kit/ex/d3/zoom-to-bounding-box),
проекция и пути — [d3-geo](https://d3js.org/d3-geo/projection).
Код перехода и управления реализован локально; эти ссылки не загружаются приложением.

При загрузке виден статус; при ошибке геоданных или ожидании дольше 20 секунд —
сообщение и кнопка повторной загрузки. Ошибка API оставляет исходный адрес и кнопку
повтора. Работа с файлами сохраняет уже обработанные пакеты и ручные правки.

## Передача готовой сборки

Проверки перед передачей: `lint`, `typecheck`, тесты Vitest и production-сборка.
Размер `dist/` — около 2.7 МБ, включая геоданные и шрифты. MapLibre загружается
лениво четырьмя частями: движок 496 КБ, геометрия 288 КБ, стили 143 КБ и шейдеры 113 КБ.
В Vite 8 используется `codeSplitting.groups` — замена устаревшего `manualChunks`.
Предупреждений о размере нет; стандартный порог 500 КБ не повышен. Рабочий поток
загружается отдельно (508 КБ), при запуске движка.

Для разделения используются исходные модули установленного `maplibre-gl@6.14.0`;
версия закреплена, пакет не изменяется. Настройки TypeScript/Oxc удаляют объявления
полей без значений, как требуется классам массивов MapLibre. Лицензия включена
в `dist/licenses/maplibre-gl.txt`. При обновлении зависимости повторить проверку 3D
и рабочего потока. Описание настройки: [Rolldown codeSplitting](https://rolldown.rs/reference/OutputOptions.codeSplitting).
Неиспользуемые стили встроенных контролов карты удалены, шрифты ограничены
Latin/Cyrillic/Cyrillic Extended в WOFF2. Поиск и заголовок появляются до запуска
графического движка. При первом обзоре страны не запускается лишний пересчёт высот.

Предыдущий замер до добавления демо, аналитики и справочника: Lighthouse 13.5.0,
Chrome 155 headless, стандартная мобильная эмуляция и simulated
throttling, локальный `npm run preview`, холодный запуск:

- `/`: Performance **89**, Accessibility **100**; FCP 2.0 с, LCP 2.6 с, TBT 310 мс, CLS 0.
- `/#files`: Performance **93**, Accessibility **100**; FCP 2.2 с, LCP 2.8 с, TBT 90 мс; MapLibre не загружается.
- В сетевых списках проверенных экранов нет запросов на внешний origin.

Первоначальные результаты были 86 / 100 для карты и 92 / 100 для файлов;

FastAPI должен отдавать `dist/index.html` на `/`, `dist/assets/` на `/assets/`,
`dist/geo/` на `/geo/` и `dist/favicon.svg` на `/favicon.svg`. Пути API обрабатываются
раньше статического приложения; ошибки API не должны возвращать `index.html`.
Маршруты интерфейса используют `#main`, `#files` и `#about`, отдельный серверный роутинг им не нужен.
Также отдаются локальные тексты из `dist/licenses/` на `/licenses/`.
Для статических ресурсов желательно HTTP-сжатие; для HTML — перепроверка кеша,
для файлов с хешем в имени допустим длительный кеш.
